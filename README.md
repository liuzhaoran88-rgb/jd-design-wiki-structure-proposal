# JD Design Wiki Knowledge Architecture

基于品牌规范和多端多 APP 场景的设计知识结构优化方案。

这份文档讨论两件事：

- 品牌规范如何在 `JD Design Wiki` 中集中管理，又能服务 APP 页面、大促、子品牌等真实场景。
- 主 APP、子 APP、小程序、PC 端如何共享设计哲学、品牌核心和基础规范，同时保留各自的 Profile、版本和页面差异。
